3.10
关闭订单卡：OrderSmartUtils.java
closeCardRequest：判断用旧接口还是新接口
用新接口：(orderNegBackReq)加入token, moduleName请求参数 >>
(closeCardCommon)加入通用请求参数并实际发请求

orderNegBackReq()
partnerId=骑行卡, status=20时，请求时加入impressionInfo参数：
queryMap.put("impressionInfo", JsonHelper.toJsonString(impressionList)序列化的json字符串);
JsonHelper：基于gson序列化库，序列化时，value为null会自动过滤

订单卡几种退场方式：
canColdExpose() 检查冷启曝光次数是否达到上限，达到上限则发送关闭请求（OrderSmartUtils.closeCardRequest）
canClickExpose() 检查点击次数是否达到上限，达到上限则发送关闭请求
canTimeExpose() 检查曝光时长是否达到上限，达到上限则发送关闭请求
canCustomExpose() 检查个性化事件是否达到上限，达到上限则发送关闭请求

构建impressionInfo：

impressionInfo.put("impressionType", xxx);

impressionInfo.put("impressionTime", xxx);

3.11
传json时，用JSONObject结构：（优点：可自动序列化，不需要调用转string的耗时操作）
```java
try {
	JSONObject jsonObj = new JSONObject();
	jsonObj.put("key", value);
} catch (Exception e) {
	// 上报异常
}
```
